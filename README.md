# Suzy Coiffure

Demo website for Suzy Coiffure, a hair salon at Rue des Chavannes 13, Neuchâtel.

Static site (HTML, CSS, JS). Open `index.html` or serve the folder:

```bash
python3 -m http.server 5178
```

- `index.html` — page structure
- `styles.css` — design system and sections
- `main.js` — WebGL hero (Three.js), GSAP scroll animations, Lenis smooth scroll
- `i18n.js` — FR / EN / DE texts, services and prices, opening hours
- `assets/img/` — illustrative stock photos (Unsplash), to be replaced with the salon's own photos
